# Fox Parker

I turn difficult PDFs, public records, and recurring document workflows into clean, traceable spreadsheets.

My work is built around three rules:

- every extracted row points back to its source file and page;
- unclear values are flagged rather than guessed;
- the final Excel or CSV file is organized for the client's actual workflow.

## Current focus

- PDF and scanned-document data extraction
- Public-record research and structured datasets
- Spreadsheet cleanup, normalization, and validation
- Repeatable document-to-tracker workflows
